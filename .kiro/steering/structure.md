## Code Organization Patterns

### Services (HTTP Endpoints)

Services extend `Service<Env>` and implement `fetch()`:

```typescript
export default class extends Service<Env> {
  async fetch(request: Request): Promise<Response> {
    return app.fetch(request, this.env);
  }
}
```

Use Hono for routing and middleware. Access Raindrop resources via `this.env` or `c.env`.

### Tasks (Scheduled Jobs)

Tasks extend `Task<Env>` and implement `handle()`:

```typescript
export default class extends Task<Env> {
  async handle(event: Event): Promise<void> {
    // Scheduled task logic
  }
}
```

### Observers (Queue Consumers)

Observers extend `Each<Body, Env>` and implement `process()`:

```typescript
export default class extends Each<Body, Env> {
  async process(message: Message<Body>): Promise<void> {
    // Message processing logic
  }
}
```

## Generated Files

- `raindrop.gen.ts` - Auto-generated type definitions for environment bindings
- Generated by `npm run generate` from `raindrop.manifest`
- **Never edit manually** - regenerate when manifest changes

## Naming Conventions

- **Files**: kebab-case (`api-gateway/index.ts`)
- **Folders**: kebab-case (`notification-handler/`)
- **Resources**: kebab-case in manifest (`smartbucket "documents"`)
- **Environment bindings**: SCREAMING_SNAKE_CASE (`env.DOCUMENTS`)
- **Types/Interfaces**: PascalCase (`interface Env`)
- **Variables/Functions**: camelCase (`requestId`, `generateCacheKey()`)

## Resource Access

Resources defined in `raindrop.manifest` are accessed via environment bindings:

```typescript
// Manifest: smartbucket "documents"
// Access: this.env.DOCUMENTS or c.env.DOCUMENTS

// Manifest: queue "notifications"  
// Access: this.env.NOTIFICATIONS

// Manifest: smartmemory "agent_memory"
// Access: this.env.AGENT_MEMORY
```

## Test Organization

- Unit tests colocated with implementation (`index.test.ts`)
- Shared test utilities in `src/_test/`
- Mock resources defined in `src/_test/mocks.ts`
- SmartBucket validation in `src/_test/smartbucket-validation.test.ts`
